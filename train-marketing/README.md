# 火车票营销配置原型

统一入口：https://903974273-cpu.github.io/-/train-marketing/

- `discount.html`：火车票辅营立减配置。
- `cashback.html`：返现金满赠配置。
- `src/`：可继续编辑的原型源文件。

原型是静态交互演示，不连接真实订单、营销或商品中心服务。检查、草稿及保存只用于本机演示。

通道类型和辅营产品使用辅营数据源的模拟数据，均通过可搜索的多选下拉框配置。通道包括便捷购票、12306购票、优享购票；产品按 `skucode-名称` 展示并记录 skucode。不在条件区域新增或手工添加通道和产品。

更新源文件后，可使用 Codex 的可视化导出工具重新生成对应完整 HTML，再发布到 GitHub Pages。
